# Level 3 Design - Dashboard and National Newspaper Workflow

## 1. Obiettivo

Questo documento definisce il design del Livello 3 di Civitas.

Il Livello 3 introduce due estensioni coerenti tra loro:
- dashboard dello stato della nazione;
- generazione automatica di un giornale nazionale periodico.

La dashboard espone dati aggregati della micro-nazione tramite endpoint JSON e aggiornamento AJAX.
Il giornale nazionale usa gli stessi dati, insieme a comunicati, leggi e storico decisionale, per generare automaticamente un contenuto periodico salvato nel database.

## 2. Scope Livello 3

Funzionalità incluse:
- endpoint JSON per statistiche della micro-nazione;
- pagina dashboard con JavaScript `fetch()`;
- visualizzazione dinamica dello stato della nazione;
- generazione automatica di giornali nazionali;
- archivio dei giornali generati;
- pagina dettaglio di un giornale;
- vincolo di unicità per periodo;
- autorizzazione alla generazione riservata a `FOUNDER` e `MINISTER`.

Funzionalità escluse:
- scheduler automatico reale;
- cron job;
- WebSocket;
- framework frontend;
- editor manuale avanzato;
- uso di AI esterna;
- SPA moderna.

## 3. Motivazione della scelta

La dashboard e il giornale nazionale sono estensioni collegate.
La dashboard mostra lo stato quantitativo della micro-nazione.

Il giornale trasforma quello stato in una narrazione periodica.

In questo modo il Livello 3 riutilizza le funzionalità dei livelli precedenti:
- cittadini;
- ruoli;
- leggi;
- voti;
- comunicati;
- decision logs;
- risorse simboliche;
- ranking.

## 4. Dashboard dello stato della nazione

La dashboard è una pagina JSP tradizionale che usa JavaScript per caricare dati JSON.

Endpoint pagina:
```text
GET /nation/dashboard?id=...
```

Endpoint JSON:
```text
GET /api/nation/stats?id=...
```

Flow:
```text
GET /nation/dashboard?id=1
-> NationDashboardServlet
-> carica Nation
-> forward nation-dashboard.jsp
-> JavaScript fetch('/api/nation/stats?id=1')
-> NationStatsServlet
-> JSON response
-> aggiornamento DOM
```

## 8. Giornale nazionale periodico

Il giornale nazionale è un contenuto generato automaticamente dal sistema.
Non viene scritto manualmente dall’utente.
L’utente autorizzato avvia la generazione, ma il contenuto è costruito dal Service usando dati applicativi.

Endpoint previsti:
```text
GET  /nation/newspapers?nationId=...
GET  /nation/newspaper?id=...
GET  /nation/newspapers/generate?nationId=...
POST /nation/newspapers/generate
```

## 9. Periodicità

Il giornale è periodico perché ogni giornale appartiene a un periodo.

Formato periodo consigliato:
```text
YYYY-MM
```

Esempio:

```text
2026-06
```

Regola:
- una micro-nazione può avere al massimo un giornale per lo stesso periodo;
- il vincolo viene controllato lato Service e lato database;
- il periodo viene scelto nel form di generazione;
- in assenza di input, può essere proposto il mese corrente.

## 10. Autorizzazioni

Lettura:
- tutti possono consultare dashboard e giornali pubblicati.

Generazione:
- solo `FOUNDER` o `MINISTER` possono generare un giornale nazionale.

Utenti non autorizzati:
- anonimi: redirect a login;
- membri senza ruolo adeguato: errore 403;
- non membri: errore 403.

## 12. Regole di generazione automatica

Il testo viene generato con template e dati.

Esempi di regole:
- se le leggi approvate sono maggiori delle respinte, il giornale descrive una fase politica positiva;
- se le leggi respinte sono molte, il giornale segnala una fase di discussione o instabilità;
- se `energy_points` è basso, il giornale suggerisce attenzione alla stabilità energetica;
- se `culture_points` è alto, il giornale descrive una micro-nazione culturalmente attiva;
- se sono presenti molti comunicati, il giornale evidenzia una comunicazione istituzionale intensa;
- se non ci sono leggi, il giornale segnala una fase istituzionale iniziale.
